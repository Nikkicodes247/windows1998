# Sharma-ji's PC — The Abandoned Computer

> 🖥️ A Windows 98 replica web experience set in a late-1990s Indian household in Bhilai.

## 🏠 The Story

The PC belongs to the **Sharma family** of Bhilai:
- **Papa (Sharma-ji)**: Steel plant clerk, Y2K prepper, forwards chain emails
- **Mummy**: Recipes, rules, and the real admin of the house
- **Rahul (17)**: Games, an unsent love letter, a school project on the Dandi March

The clock is frozen at **31 December 1999, 11:57 PM**. The computer was abandoned that night, and no one came back for it — until now.

## 🚀 How to Explore

1. **Power on** the computer (click the button)
2. **Watch the BIOS** (press DEL for a surprise)
3. **Log in** (any password works — it's Windows 98)
4. **Explore!**
   - Double-click desktop icons
   - Open the Start menu
   - Check files in My Documents
   - Play Snake II and Minesweeper
   - Open Internet Explorer (dial-up required!)
   - Read Outlook emails
   - Try the MS-DOS Prompt
   - Run Y2K_Panic.exe at your own risk

## 🛠️ Tech Stack

- **HTML, CSS, Vanilla JavaScript** — no frameworks
- **98.css** (CDN) — Windows 98 UI components
- **Web Audio API** — all sound effects
- **Emoji + CSS** — all visual assets
